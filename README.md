# Vehicle Service and Parts Management System

A Python-based Vehicle Service and Parts Management System designed to demonstrate practical proficiency with data structures, algorithms, object-oriented programming, and modular software design.

The project models the core operations of an automotive repair shop while assigning each data structure to a task where it provides an efficient and realistic solution.

## Project Goals

The main goals of this project are to:

- Build a functional vehicle service management application
- Apply data structures to real-world automotive operations
- Demonstrate understanding of time and space efficiency
- Practice object-oriented programming
- Organize the system into reusable Python modules
- Implement core data structures without relying only on built-in libraries

## Current Core Features

The first version of the application focuses on four main operations:

- Add a vehicle
- Add a part
- Create a service request
- Process the next service request

Service requests are assigned urgency scores and placed into a priority queue so that the most urgent repair can be processed first.

## Planned Application Features

The completed application may manage:

- Vehicles
- Customers
- Repair appointments
- Parts inventory
- Service requests
- Technicians
- Shop locations
- Repair history
